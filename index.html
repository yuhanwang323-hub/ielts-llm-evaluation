研究问题

为什么国产大模型在英语教学反馈场景中总是"差一点"?

雅思备考者中,基础 5.5-6.5 分段的学生最需要 AI 辅助。他们的共性特征是:提升难度高、需要大量练习、英语基础较弱、倾向使用国产工具。但市面上的国产大模型在英语教学反馈场景下的能力从未被系统性评估——学生常常不知道哪款模型更适合自己。

本研究以三款国产模型(DeepSeek、豆包、通义千问)为主要分析对象,三款英文模型(ChatGPT、Claude、Gemini)为行业参照组,雅思考官真实评语为金标准基准线,量化定位差距、揭示反直觉发现,并输出可落地的产品改进方案。

三条分析路径的交叉验证

多模型横评的最大风险是评估结论的主观性。本研究通过量化指标、人工盲评、索引行分析三种方法互补,降低单一视角的偏差。

核心发现

四个反直觉的量化结论

01

国产模型与考官的评估语言完全脱钩

考官评估类词占比 53%,而所有国产模型均低于 20%。更关键的是,N-gram 分析中考官的专业搭配(cohesive devices、overall progression、generally adequate)在六款 AI 模型中无一命中——不是少,是零。这意味着 AI 反馈的话语体系与雅思评分系统完全脱节,评分可信度存疑。

Key Metric
考官评估词占比 53%
国产模型均值 <20%
专业搭配命中 0 / 6
02

ChatGPT 输出最长,但词汇丰富度最低

ChatGPT 总词数 2,175(考官的 7.3 倍),但 TTR 仅 0.34——是所有模型中最低的。原因是其 86.2% 的内容词来自对学生原文的大量复述,而非专业评估。消除篇幅影响后,DeepSeek 的 Guiraud 指数(16.92)反而领先所有海外模型。

Key Metric
ChatGPT TTR 0.34
DeepSeek Guiraud 16.92
ChatGPT 内容词占比 86.2%
03

反馈策略高度分化,用户却无法切换

索引行分析揭示各模型的原生风格:豆包"逐条纠错型"(原文引用 25 次、修改示范 0 次)——学生知道错在哪但不知道怎么改;ChatGPT"解释教学型"(举例 16 次)——详细但冗长;Claude"结构分析型"——精准但技术化。这些风格本身没有优劣,但用户无法按自己的场景主动切换。

Key Metric
豆包 原文引用 25 次
豆包 修改示范 0 次
ChatGPT 举例说明 16 次
04

DeepSeek 在"反馈优先级"维度唯一领先

三人盲评结果中,DeepSeek 总均分 4.4,与 ChatGPT 并列最高;在"反馈优先级"维度以 4.5 分领先所有模型(含 ChatGPT 的 4.0 分)——它在 Task 2 反馈中明确告诉学生"先改什么最能提分"。这一发现直接反哺了产品的核心功能设计:Top3 问题摘要模块。

DeepSeek 总均分 4.4 / 5

产品方案

从评测发现到产品原型的完整链路

基于核心发现,独立产出 5 页产品原型,每个页面的设计决策都对应一项量化数据支撑。这不是"先有设计再讲故事",而是"数据告诉产品该往哪走"。

  1. 01
    作文提交页
    选择题型 + 目标分数段 + 反馈模式(快速纠错 / 深度教学 / 模拟考官)
    基于发现 03:反馈角色未分离
  2. 02
    反馈主页面
    四维评分可视化 + Top3 问题摘要模块
    基于发现 04:国产模型反馈优先级缺失
  3. 03
    详细反馈 · 快速纠错模式
    原文错误高亮 + 修改示范 + 三级优先级标记
    融合豆包逐条对照优势,补齐其优先级缺失
  4. 04
    详细反馈 · 深度教学模式
    完整教学链:原文引用→错误分析→修改示范→举例说明→练习建议
    融合 ChatGPT 举例教学策略(16 次 · 最高)
  5. 05
    反馈语言设置
    中文 / 英文 / 中英对照切换,专业术语自动附中文解释
    基于人工评估:语言可理解性是国产模型核心短板

架构延伸建议

RAG 架构规划与国产模型训练侧权重调整

产品层改造无法解决模型本身的能力缺陷。报告最后提出两条面向研发团队的技术建议:

一、外挂 RAG 知识库——引入三个垂直语料库:剑桥考官真实评语库、雅思分段范文库、L1 负迁移错误库,让模型在生成反馈时检索真实评语体系,弥补自身训练数据中的专业术语缺失。

二、训练权重向 TR 和 CC 倾斜——量化数据显示所有模型都"偏科语法(GRA)、弱于任务回应(TR)与连贯性(CC)",原因是语法错误最容易自动检测。但对目标用户(5.5 分段学生)而言,TR 和 CC 对总分的拉动作用远大于 GRA。训练侧的权重调整比后端挂载语料更能系统性改善能力结构。
